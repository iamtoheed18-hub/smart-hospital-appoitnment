# Smart Hospital - MedCare Hospital Appointment System

A modern, responsive Hospital Management & Appointment Booking website.

## Features
- 🏥 Comprehensive Hospital Overview & Services
- 👨‍⚕️ Doctors Directory with Department Filtering
- 📅 Interactive Appointment Booking
- 📋 Instant Appointment Confirmation with Local Storage
- 📊 Patient Dashboard with History & Stats
- 📱 100% Mobile Responsive & Modern UI

## Project Structure

## How to Deploy on Vercel
1. Upload this repository to GitHub.
2. In Vercel, click **Add New Project** and select your `smart-hospital` repository.
3. Keep default settings (Framework: **Other** / Root: `./`).
4. Click **Deploy**!
